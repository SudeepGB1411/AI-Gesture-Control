# Chandana Birthday Surprise (React + Vite)

A single-page, animated coastal birthday experience built with React, Tailwind CSS, and Framer Motion.

## Tech Stack
- React + Vite
- Tailwind CSS
- Framer Motion

## Run Locally
```bash
cd birthday-surprise
npm install
npm run dev
```

## Production Build
```bash
cd birthday-surprise
npm run build
npm run preview
```

## Deploy to Vercel
1. Push this repository to GitHub.
2. In Vercel, click **Add New Project** and import the repository.
3. Set **Root Directory** to `birthday-surprise`.
4. Keep defaults:
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. Click **Deploy**.
6. Share the generated Vercel URL as the birthday surprise link.
