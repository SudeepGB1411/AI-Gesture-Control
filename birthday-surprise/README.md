# Birthday Surprise Web App

A single-page animated birthday experience for Chandana built with React, Vite, Tailwind CSS, and Framer Motion.

## Run locally

```bash
cd /tmp/workspace/SudeepGB1411/AI-Gesture-Control/birthday-surprise
npm install
npm run dev
```

## Production build

```bash
cd /tmp/workspace/SudeepGB1411/AI-Gesture-Control/birthday-surprise
npm run build
npm run preview
```

## Deploy to Vercel

1. Push the repository branch that contains the `birthday-surprise` folder.
2. In Vercel, choose **Add New > Project** and import the repository.
3. Set the **Root Directory** to `birthday-surprise`.
4. Keep the default framework preset as **Vite**.
5. Confirm the build settings:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
6. Deploy and share the generated Vercel URL.

## Tech stack

- React 19
- Vite
- Tailwind CSS
- Framer Motion
